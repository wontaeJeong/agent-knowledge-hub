- 원래 React DOM probe에서 폐기를 한 번 수락해도 이름 `pending name`과 검색어 `changed term`이 남았다. 새 `views.test.tsx` 회귀도 취소 후 입력 보존을 통과한 다음, 수락 후 빈 값 기대에서 실제 두 편집값을 반환해 실패했다.

- 수정 후 React DOM 저장 보기 17개 통과. 독립 probe 재실행에서 폐기 수락 한 번에 두 값 모두 비었다. 별도 probe로 합성 IME 이름 복원과 조건 충돌, 빠른 검색 전달 후 403과 폼 폐기, 저장 중 두 입력 잠금과 저장 후 값, 변경 이탈 차단을 확인했다.

# 제품 기능 PR 병합 기록

2026-11-14 사용자가 기능 PR 12개에 대해 “머지”를 요청했다. 앞선 설계의 PR 유지 지시는 이 후속 승인으로 변경되었으며 제품 범위와 North Star는 변경하지 않는다. 기존 탐색 PR #30은 이번 승인 대상에 포함하지 않는다.

병합 순서는 #35 → #32 → #33 → #34 → #39 → #37 → #36 → #38 → #41 → #40 → #42 → #43이다. 저장소는 squash 병합만 허용한다. 각 기능의 격리 worktree에서 선행 변경을 조합하고 전체 필수 검사를 실행한 뒤, 최종 head의 필수 CI가 모두 통과해야 해당 PR을 main에 병합한다. 기본 체크아웃은 매 병합 뒤 원격 main으로 fast-forward한다.

선행 squash 결과와 이미 포함한 기반 트리가 모든 파일에서 동일함을 `git diff --quiet`로 확인한 경우에만 내용 변경 없이 main의 이력을 연결한다. 기반 커밋이 기능 브랜치의 조상인지도 확인하며, 트리가 다르거나 사용자 변경이 있으면 이 절차를 중단한다. 이력 연결 뒤에도 새 최종 head의 CI를 확인한다. 강제 push나 저장소 병합 정책 변경은 사용하지 않는다.

## 충돌과 검증

- 인계·실패 기록은 양쪽을 보존하고 현재 현황은 각 기능의 구현과 미검증 범위를 합친다.
- 계정·알림·수집기·휴지통 route와 화면, 기존 역할 호환·보호된 모델 대상·복원 메타데이터·보존 실행, 개인 대화의 현재 context와 평가 입력 seal을 함께 유지한다.
- 최종 코드(`server`, `src`, `scripts`, `index.html`, `package.json`)는 앞서 검증한 통합 리허설 `757849e`와 파일별로 동일함을 확인했다. 앞선 리허설은 Node24 전체 검사와 PostgreSQL17 111파일·821시험을 통과했다. 실제 합성 DB의 교차 기능 삭제·복구 권한 및 보존 제어 테이블 회귀도 함께 포함한다.
- 이번 병합 준비의 각 단계에서 `npm run check`를 실행했다. 최종 조합의 재실행 결과와 PR별 최종 CI 링크는 PR 본문에 기록한다.

사내 인증·실제 모델의 의미 품질·업무 효과·운영 인수·외부 백업·CAS 물리 삭제는 이 병합의 검증 범위가 아니다. 기존 PR #30의 연결 충돌과 UI 증거는 별도 후속이다.

이번 최종 조합 재검증도 통과했다. Node24 `npm run check`는 프런트엔드172개·import16개·요구사항251개 연결·서버 타입·빌드·HTTP smoke를 통과했고, 전용 tmpfs PostgreSQL17에서 전체111파일·821개 테스트가 exit 0으로 끝났다. 로그는 `/private/tmp/akh-merge-p43-check.log`, `/private/tmp/akh-merge-final-pg17.log`에 있다. 실제 main 병합 직전에는 별도로 각 최종 head의 원격 CI를 확인한다.

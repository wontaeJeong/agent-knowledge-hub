# Agent-Native 운영 콘솔과 명시적 UI 목업

## 의도와 범위

사용자는 전체 웹 UI 재검토, 누락 기능의 목업, 의미 있는 사용량 대시보드, 사용자/필수 관리 기능 개선, 목업 제시와 PR·머지를 요청했고 추가 질문 없이 판단해 진행하도록 위임했다. 최신 `origin/main@e89921c`를 작업 브랜치에 fast-forward했다. 기존 React/TypeScript/Vite·plum 토큰/브랜드·서버 API를 유지하는 것은 구현자의 선택이다.

에이전트에게 지식과 실행 환경을 제공하는 서비스의 운영 콘솔이다. 사람의 문서 생산성 순위 대신 Ingest → Review → Query → Lint → 재편입의 상태, 실패/검토 병목, 근거/적용 조건과 미평가 상태를 앞세운다. 사람이 근거를 읽고 검토하는 기존 경로는 보존한다.

## 화면과 경계

- `/` 소개, `/?app=1` 실제 서버 UI, `/?demo=1` 기존 합성 데모를 유지한다. `/?preview=1`은 인증/서버 요청 없는 독립 합성 UI 목업이다. 실제 서버 오류를 목업으로 대체하지 않는다. 목업 버튼은 메모리에서만 상태를 변경하며 새로고침 시 초기화한다.
- 공통 앱 셸: 데스크톱 그룹별 사이드바, 모바일 접는 탐색, 경로/현재 화면, 테마, 서버/목업 표시, 키보드 본문 이동. hash 기반 화면 직접 링크/뒤로가기.
- 운영 개요: 현재 접근 가능한 지식/원본/검토/작업 상태와 조치 링크, 서비스 호출 집계의 성공·실패/분모/기간/범위, 모델 비용·토큰·품질·후속 업무 효과의 미수집/미평가 표시. 실제 집계 실패는 오류/재시도로 표시한다.
- 기존 발행 지식·원본/편입·변경 검토·질문/재편입·Lint·작업·사용량은 동작을 보존한다. 목업의 동일 화면은 합성 응답으로만 시연한다.
- 관리 목업: 사용자/세션/접근 요청, 팀/그룹/공간 역할·소유권·공개 범위, 서비스 주체/범위 토큰, API/MCP/커넥터, 작업 예산/일정·중지, 검토 보호/공유·반출, 알림/감사, 문서 수명주기/편집·첨부, 평가/운영 준비. 검색/필터/상세/검증·확인/모의 상태 변경을 제공한다.
- 전체 239+12개 요구사항은 화면 연결과 남은 한계를 검색 가능하게 노출한다. 목업 제공과 수용 기준 통과를 구별하며 기존 기준 상태를 올리지 않는다. 선택·확장 기능도 목록에서 보존하되 비활성 정책을 명시한다.

## 안전·비목표

ADR005의 공간 5역할/Owner는 제안 목업이다. 현행 reviewer를 Admin/Owner로 승격하지 않고 실제 인증/DB/ACL을 교체하지 않는다. 서비스 주체는 승인·발행하지 못하고 토큰의 승인/관리 권한을 제공하지 않는다. 마지막 Owner 제거·개인 공간 공개 확대·원본 제한 우회는 목업에서도 거부한다. 실제 키를 입력/생성/저장하거나 브라우저 관리 상태를 보안 통제로 사용하지 않는다.

운영 게이트·자연어 의미 품질·실제 모델/부하/사내 인수를 새로 완료하지 않는다. UI 목업이 백엔드 전체 구현을 의미하지 않는다. North Star 의미·원본·승인·발행 엔진은 변경하지 않는다. 기존 지식 내용은 바꾸지 않고 운영 상태와 지식 갱신 순환의 가시성을 개선한다. 효과 평가는 EVALUATION의 대조 실험 전에는 목표다.

## 검증과 산출물

### 최신 main 통합 결정

작업 중 `origin/main@31b7d9a`에 PR12의 실제 자료 편입/Organization·Team·5역할/초대/worker가 추가되어 통합했다. 위 초기 기준의 ‘3역할만 구현’은 시작 시점 설명이다. 실제 앱의 `imports`와 `access`는 최신 실구현을 보존하며 확장 목업으로 대체하지 않는다. 미구현 전역 세션/서비스 주체/범위 토큰/문서한정 공유 등만 별도 목업 경계를 유지한다. 초기 스펙의 메모리 UI를 서버 권한 이관으로 해석하지 않는다.

순수 집계/라우팅/목업 격리/상태 전이/요구사항 커버리지 회귀를 먼저 작성한다. `npm test`, `check:requirements`, `check:server`, `build`, HTTP smoke와 390/1440px 실제 Chromium 검증을 수행한다. 표 최소 너비·내부 스크롤·25건 페이지, 첫 결론 위치, 문서 길이, 14px 이상 그래프 글자, 모바일 탐색/키보드/테마/확인 대화상자를 확인하고 전후 수치·스크린샷을 보존한다. PR 본문에 목업 링크/캡처·실제 검증·미구현 제약을 제공한다.

# LLM 사내 위키 인수 시나리오

이 목록은 구현 후 실행할 인수 기준이다. 현재 실행 결과나 통과 보고서가 아니며 모든 시나리오는 미실행 상태다. 요구사항 항목별 수용 기준도 함께 검증해야 한다. 한 시나리오가 여러 요구사항을 묶어 확인하므로 시나리오 수를 테스트 케이스 총수로 간주하지 않는다.

테스트는 익명화한 자료와 시험 계정으로 격리 환경에서 수행한다. 권한·삭제·복구 시험에서 실제 사내 비밀을 외부 모델에 전송하거나 직원에게 시험 알림을 발송하지 않는다.

## 시험 결과 기록

각 실행에는 제품 빌드, 이미지 다이제스트, 스키마, 모델·프롬프트·정책 버전, 자료 fixture, 계정 역할, 실행 시각, 기대·실제 결과, 증거, 결함과 재시험 결과를 남긴다.

## 출시 판정

첫 실제 사내 운영은 활성화 범위의 필수 요구사항, 권한 행렬, 중대 보안 결함 해소, 실제 도구 연동, 데이터 복원, 운영 인계, 정의한 부하 및 AI 품질 기준을 통과한 뒤 판정한다. 운영 중에만 측정할 수 있는 월간 가용성은 계측 준비와 오류 예산 정책을 먼저 검증하고 실제 운영으로 추적한다.

성능·품질·복구 수치는 요구사항 기준안의 제안이다. 실제 규모와 사내 모델로 검증하기 전에 보장값으로 안내하지 않는다. 미달이면 시스템 또는 목표와 적용 범위를 근거와 함께 재설계하며 테스트를 삭제해 통과시키지 않는다.

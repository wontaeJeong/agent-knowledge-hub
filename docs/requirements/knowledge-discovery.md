# 지식 탐색과 통계 요구사항

기준일: 2026-11-11. 이 문서는 기존 239개 기준 및 CORE 요구사항을 대체하거나 수용 완료로 변경하지 않는다. 연관: ACL-008, SRH-003/008/010, QNA-001, CORE-002/007/012. 제품 목표와 현재 구현·미검증을 구분한다.

| ID | 요구사항 | 수용 기준과 현재 구현 |
| --- | --- | --- |
| DSC-001 | 사용자가 접근 가능한 자주 참조되는 지식을 쉽게 찾는다. | **부분 구현:** 현재 권고 대상 문서의 명시적 내부 연결(`Page.links`)을 연결한 서로 다른 발행 문서 수로 순위화하고 문서 고유 링크로 이동한다. 접근 불가 문서와 연결은 제외한다. 위키 링크를 질문 인용이나 독립 근거로 혼동하지 않는다. 전체 사용자에게 안전하게 제공할 공간 공통 질문 인용 순위는 별도 집계 정책이 필요하다. |
| DSC-002 | 기간별 트렌딩과 자주 인용된 문서를 구분해 제공한다. | **부분 구현:** 기간 중 최근 버전이 갱신된 발행 문서가 연결한 대상을 트렌딩으로 표시한다. 이는 새로 생긴 링크나 조회 급증이 아니다. 질문 인용은 선택 기간에 저장된 답변 하나당 페이지를 최대 한 번 센 별도 순위다. 조회수·증가율·상승/하락 화살표는 기록이나 비교 기준이 없으므로 표시하지 않는다. |
| DSC-003 | 통계를 시각화하고 기간·정의·접근 범위를 확인할 수 있다. | **구현:** 7/14/30/90 UTC 일자 기준의 인용 일별 막대와 데이터 표, 합계 및 순위, 빈 상태·로딩·오류·재시도를 제공한다. 일별 및 인용 값은 선택 기간, 전체 연결 수는 조회 시점 기준임을 명시한다. 오늘은 진행 중이며 기간 밖 데이터나 미수집된 API 사용은 표시하지 않는다. |
| DSC-004 | 권한·비공개 질문·원본과 파생 데이터의 경계를 유지한다. | **구현:** 서버에서 공간·현재 문서/원본 권한과 계보를 확인한다. 개인에게는 본인 답변만, 기존 `usage.read_aggregate`가 있는 공간 관리자(레거시 검토자 포함)에게는 접근 가능한 입력의 공간 집계를 보여준다. 질문·답변 본문, 질문자, 입력 ACL은 응답하지 않는다. 보류 중인 답변과 접근 불가·변경된 입력은 제외하고 세션을 재검사한다. 권한이 없으면 제목·개수·연결도 노출하지 않는다. 새 인용 이벤트 저장 없이 기존 `runtime_answers`를 사용한다. |
| DSC-005 | 대규모에서도 정확하고 안전하게 동작하며 개인정보 정책을 따른다. | **미완료:** 현재는 선택 기간 원본 답변을 최대 2,000건까지 처리한다. 초과하면 불완전한 순위를 반환하지 않고 오류를 반환하므로 기간을 줄여야 한다. 독립된 공통 인용 집계의 허용 대상, 최소 집계 크기·차분 추론 대응, 수집 목적/보존·삭제, 위변조·중복·봇 방지, 재처리와 ACL 철회 전파, DB 부하·복구를 정책과 실측으로 정해야 한다. 사용자가 3만 명인 운영 규모를 보장하지 않는다. |

## 데이터 의미와 동작

- `from`은 선택한 날짜 수만큼 포함하는 UTC 자정, `to`는 서버 조회 시각이다. 답변마다 한 문서의 인용이 반복돼도 한 번이다. 범위 내 접근 가능한 모든 입력의 현재 envelope가 일치하고 해당 인용 버전이 현재 버전인 답변만 센다. 따라서 기록의 삭제·버전 또는 ACL 변경 시 과거 수치도 감소할 수 있다. 결측/과거/현재를 소급해 복원했다고 주장하지 않는다.
- 일반 사용자도 현재 접근할 수 있는 문서 간 연결 및 트렌딩을 볼 수 있다. 타인의 **질문 인용 활동**은 기존 집계 권한 없이 표시하지 않는다. 따라서 현 단계의 일반 사용자 인용 순위는 공간 전체 인기 순위가 아니다. 안전한 공간 공통 인용 순위는 DSC-005를 해결한 뒤 제공한다.
- 현재 권고 대상은 생애주기·시행일·대체 관계에 따른 검색 자격이며, 공식성 또는 독립 검증을 의미하지 않는다. 지식 품질·정확성·후속 에이전트 성과는 이 지표로 판정하지 않는다.
- `/api/v1/discovery?days=7|14|30|90`은 기존 서버 인증과 현재 공간을 사용하고 `Cache-Control: private, no-store`를 따른다. 인덱스만 추가하며 사용자별 추적 데이터나 원본을 복사하지 않는다. 선택 기간에 2,001개 이상의 후보 답변이 있으면 `DISCOVERY_CAPACITY`를 반환한다.
- 화면의 합성 미리보기는 별도 목업 데이터이고 운영 데이터의 대체가 아니다. 성능 개선 및 도입 전에는 노출 회귀, 보존/삭제, 대량 기록과 권한 변경 경합, 접근성·운영 환경 및 검색 품질을 검증한다.

# 계정·세션 화면 검증

2026-11-14, Node24/Vite + Playwright Chromium, 실제 React 앱 `?app=1#account`. 합성 principal/공간과 두 세션을 API 응답으로 주입했다. 실제 IdP 로그인·회사 계정·외부 네트워크 송신은 사용하지 않았다. HTTP/DB 권한 검증은 `server/identity/native-integration.test.ts`에서 별도로 실행했다.

- [1440×1000 데스크톱](desktop-1440.png): 본인 두 세션과 현재 세션 표식, 절대 만료, 개별/전체 종료 UI.
- [390×844 모바일](mobile-390.png): 세션 정보와 확인 입력·버튼이 읽히며 가로 넘침 없음.
- [390×844 종료 결과](signed-out-390.png): 확인란에 Space, 종료 버튼에 Enter를 사용했다. 보호 화면이 제거되고 제품 세션 종료와 외부 인증 로그아웃 미구성 안내가 함께 남는다.

합성 브라우저 응답은 실제 인증·서버 철회 성공의 증거가 아니다. 실제 HTTP/DB 시험에서는 본인/타인, CSRF, 쿠키 삭제, 비활성 신원과 미구성 경로를 검증했다. 별도 리뷰에서 발견한 늦은 `/me` 응답의 보호 UI 복원 및 사라지는 로그아웃 결과는 실제 App 회귀로 수정 전 실패·수정 후 통과를 확인했다.

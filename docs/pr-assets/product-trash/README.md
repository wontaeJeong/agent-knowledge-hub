# 휴지통 사용자 복구 UI 확인

Chromium + Node24.22.2 Vite, http://127.0.0.1:5184/?app=1#workflows. 합성 사용자/공간/문서와 API 응답으로 1440×1000 및390×844 화면을 확인했다. 실제 SSO/회사 자료/보존 정책 인수가 아니다.

휴지통 이동·유예 만료 시각, 만료만으로 삭제하지 않는 안내, 대체 상위 위치 및 새 제목 입력을 확인했다. 문서 복구 버튼에 키보드 Enter→확인창 수락→합성 요청 성공 후 휴지통0을 확인했다. 상위 화면 갱신 후 완료 메시지는 유지되지 않았으므로 메시지 확인을 성공 증거로 사용하지 않았다. 실제 복구 권한/ID·이력/충돌은 별도 DB 회귀 결과를 따른다.

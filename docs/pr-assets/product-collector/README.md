# 선택 자료 수집 화면 검증

2026-11-14, 실제 React/Chromium + Node24/Vite. `?app=1#integrations`에 합성 계정·연결·세션 응답을 주입했다. 실제 설치나 사용자 메시지를 수집하지 않았다.

- 1440×1000 및390×844에서 승인 연결/세션 선택, 정확 메시지 ID, 선택 도구 출력 및 개인 원본 저장 설명을 확인했다.
- 키보드 Enter로 선택 자료 가져오기를 제출하고 합성 성공 응답 표시를 확인했다. 이후403 새로고침에서 연결 목록·입력·이전 성공 메시지가 제거됐다. 가로 넘침은 없었다.
- 실제 인증 HTTP/DB 및 HTTPS 전송은 별도 합성 서버 회귀에서 검증했다. 브라우저 주입 응답은 실제 수집 성공의 증거가 아니다. 현재 설치된1.15.0은 이2.2.2 수집기 지원 대상이 아니다.

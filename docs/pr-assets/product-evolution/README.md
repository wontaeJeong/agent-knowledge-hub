# 지식 갱신 후보 화면 검증

2026-11-14, Node24/Vite + Playwright Chromium, 실제 React 앱 `?app=1#review`. 합성 API 응답의 기존 페이지 v2 갱신 후보를 표시했다. 실제 모델 응답이나 품질 평가의 증거로 사용하지 않는다.

- 1440×1000과390×844에서 변경 이유, 기존 페이지 분류, 미검증 후보의 조건·시점·불확실성과 원본 버전/위치를 확인했다.
- 상세 펼침을 통해 후보와 기준 버전을 확인했고 모바일 본문에 가로 넘침이 없었다.
- 실제 HTTP/DB/loopback 모델, 원본·권한 철회와 원자 발행은 별도 `server/runtime/evolution.test.ts`에서 확인했다. 리뷰에서 발견한 제안 후 보호 상태 변경은 공개·승인·발행 경계의 RED→GREEN 회귀로 수정했다.
- 실제 사내 모델 의미 품질과 다운스트림 성능 개선은 미검증이다. 후보 승인은 독립 실행 검증이나 진실 판정이 아니다.

# 사용량 대시보드 UI 검증

1440×1000 데스크톱, 390×844 모바일에서 브라우저로 검증한 캡처다.

- `usage-measured-*`: 로컬 PostgreSQL 시험 workspace에서 실제 서비스 조회 15회(성공 12, 실패 3)를 실행해 생성한 집계 응답을 브라우저 요청에 주입했다. 운영 트래픽이나 완성된 SSO 연결의 증거가 아니다. 화면의 워크스페이스 전체는 이 시험 workspace다.
- `usage-disconnected-*`: 정적 데모의 실제 미연결 상태. 오류를 0건/합성 데이터로 대체하지 않는다.
- `usage-empty-*`: 빈 응답의 UI 검증용 fixture. 측정 결과와 구분한다.
- `usage-loading-*`: 응답 지연 상태의 UI 검증용 네트워크 지연.
- `usage-error-*`: 인증 실패 및 응답 오류 상태. 오류 본문에 자격증명/서버 원문을 표시하지 않는다.
- `usage-self-*`: 본인 범위 응답 UI 검증용 fixture. 서버의 본인 범위 필터는 별도 DB 통합 시험으로 검증한다.
- `usage-30days-*`: 30일 선택/가로 스크롤 UI 검증용 fixture. 30일 운영 측정이 아니다.
- 라이트/다크, 기간 선택, 재시도, 모바일 탐색 메뉴, 그래프/표 키보드 내부 스크롤을 확인한다.

테스트 fixture 및 캡처에는 실사용자·사내 원본·비밀을 포함하지 않는다. 원래 데모의 역할 선택과 브라우저 업무 동작은 서버 사용량 수집 대상이 아니며 운영 서버 연결은 후속 작업이다.

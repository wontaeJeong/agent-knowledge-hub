# 문서 탐색 UI 검증

2026-11-16, Node 24.22.2 + Vite 8.3.5 + 실제 Playwright Chromium headless. `/?app=1&space=synthetic&document=topic`의 React 운영 화면을 로컬에서 실행했다. 모든 사용자·본문·문서 관계는 합성 API 응답이며 실제 사내 계정이나 자료는 없다. 인증·DB 검증은 별도 native HTTP 회귀다. 브라우저 화면을 실제 서버 E2E 증거로 간주하지 않는다.

- [1440px 문서 탐색](desktop-1440.png), [390px 문서 탐색](mobile-390.png): 개인 목록·목차·코드/표 검색 2건과 두 번째 위치·펼친 한 단계 관계.
- [1440px 링크 완성](completion-desktop-1440.png), [390px 링크 완성](completion-mobile-390.png): 개인 초안을 열고 제목 입력 뒤 자동 조회된 링크 후보. 로컬 복구는 합성 서버의 명시적 403으로 금지하며 서버 초안 입력 경계를 보인다.
- 실제 확인: 목차와 위치 이동, 자동 조회 후보, `mark` 2개, 현재 일치 1개, 브라우저 `pageerror` 0건, 두 뷰포트의 가로 넘침 없음. 전체 페이지 스크린샷이며 뷰포트는 각각 1440×1100, 390×844다.
- 최초 작성 화면 캡처는 복구 권한 API에 일반 빈 목록을 반환한 fixture 때문에 계정 바인딩 검사에 의해 초안이 닫혀 실패했다. 명시적 권한 거부 응답 계약으로 수정한 후 재실행했다. 제품 권한 검사를 우회하지 않았다.

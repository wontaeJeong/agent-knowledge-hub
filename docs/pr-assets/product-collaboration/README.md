# 사용자 알림·검토함 화면 검증

2026-11-14, Node24/Vite + Playwright Chromium, 실제 React 앱 `?app=1#notifications`. 합성 계정·알림·검토 배정·미구성 전달 이력을 API 응답으로 제공했다. 실제 외부 이메일은 발송하지 않았다.

- 1440×1000과390×844 화면: 개인 시간대/요약/조용한 시간 설정, 인앱 읽음, 별도의 이메일 전달 상태 및 검토함을 확인했다.
- 키보드 Enter로 읽음 표시 후 상태 변경을 확인했다. 표는 이름과 키보드 포커스가 있는 내부 가로 스크롤 영역이며 페이지 전체 넘침은 없었다.
- 403 응답 후 새로 고침 시 이전 제목과 링크가 사라지는 화면을 캡처했다. 늦게 도착한 이전 성공/실패 응답은 별도 실제 React 경합 회귀에서 확인했다.
- 실제 HTTP·DB·서명된 합성 TLS 수신자 증명/게이트웨이 어댑터 회귀는 별도로 수행했다. 실제 사내 IdP·메일 승인/전달·운영 인수를 완료했다고 주장하지 않는다.

# 체크포인트 화면 참고

- 대상: `?preview=1`의 합성 운영 개요와 편집·수명주기 목업, `?app=1#imports`와 `#activity`의 실제 프런트엔드 화면.
- 환경: 로컬 Vite + Chromium, 1440×900과 390×844 CSS px. 실제 서버에 연결하지 않는 합성 데이터다.
- 편입 화면에서 문서 폭은 각각 1440px·390px, 문서 높이는 1399px·1862px, 첫 제목 위치는 100px·237px이었다. 이는 캡처 시점의 측정이며 전체 UI·키보드 접근성 인증이 아니다.
- 편입 화면은 인증과 목록을 합성 HTTP 응답으로 대체했다. 이 캡처는 실제 서버의 작성·승인·모델·권한 기능이나 접근성 인수 검증의 증거가 아니다. 실제 서버의 변경 화면과 최종 이미지 브라우저 검증은 미완료다.

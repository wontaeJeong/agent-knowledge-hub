# 실행 데모 시나리오

## 준비

압축본: npm run demo. 소스: npm ci → npm run build → npm run demo. http://127.0.0.1:8080/#/compile 을 연다. 합성 예시만 사용하며 검토자 역할로 시작한다. 설정에서 초기화할 수 있다.

## Ingest

원본 등록을 누르고 선택 자료 편입을 실행한다. 준비된 원본은 두 개의 `## 지식:` 절을 갖는다. 개념 두 개와 기존 주제의 연결 목록을 하나의 변경 집합으로 제안한다. 내용을 펼쳐 비교하고 변경 집합 승인 → 승인 집합 전체 발행을 실행한다. 인덱스에 세 페이지의 현재 버전과 연결이 나타난다. 원본 본문은 바뀌지 않는다.

## Query와 축적

질문과 축적에서 기본 질문을 실행한다. 오프라인 모드는 발행본의 정확한 발췌와 인용 버전을 보여준다. 인용 링크는 고정 버전을 연다. 답변을 위키로 편입한 뒤 자료 편입에서 새 집합을 승인·발행한다. 질문 결과가 새 페이지로 축적된다. 근거 부족 질문 예시는 모르는 내용에 답을 조작하지 않는다.

## Lint

자료 편입에서 상충 자료 예시 등록 → 편입 → 승인·발행한다. 주간 점검에서 Weekly 점검 실행을 누른다. 동일 조건의 requests-ca-bundle 값이 상충함을 원본 두 개와 함께 표시한다. 그 밖의 고립 페이지·근거 누락·검증일 누락도 실제 현재 데이터에서 계산한다. 최신 수정일을 검증일로 사용하지 않는다. 자연어 전반의 의미 모순 판별은 아니다.

## 실제 모델

MODEL_SETUP.md를 따라 서버의 .env를 설정하고 실행기를 재시작한다. 실행 엔진에서 연결된 모델을 고른다. 실제 API로 기존 위키와 원본을 종합하는 편입 및 질문을 수행한다. 실패·스키마 오류·가짜 인용은 오류로 남고 반영하지 않는다. 기본 오프라인 동작을 LLM 호출로 표시하지 않는다.

## 유지하는 기존 시연

문서의 버전 복원·로컬 공유·만료·철회·피드백과 활동 기록은 계속 사용할 수 있다. 이전 개별 변경안 화면은 초기 데이터 호환 경로이며 새 변경 집합은 지식 컴파일에서 검토한다. 수동 편집은 데모 즉시 발행이고, 새 편입·질문 제안은 승인·발행을 거친다.

## 경계

단일 브라우저 저장이며 프로덕션 인증·권한·다중 사용자·무인 스케줄러·실제 MCP 서버는 미구현이다. 모델 연결 코드는 제공하지만 실제 사내 모델 품질과 운영은 미검증이다. 전체 요구사항은 로드맵에 유지한다.

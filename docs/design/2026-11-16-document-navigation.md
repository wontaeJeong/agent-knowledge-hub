# 문서 탐색과 개인 목록 — 2026-11-16

관련 요구사항: EDT-007/010, SRH-009/010. 이 작업은 North Star의 인간 탐색·검토와 연결된 지식 재사용을 개선한다. 지식 본문·권한·발행 상태를 자동 변경하거나 지식 품질·후속 에이전트 성능 개선을 주장하지 않는다.

## API와 연결

- `GET /api/v1/workflows/pages/:id/navigation`: 선택한 현재 발행본의 `pageId`, `version`, `links`, `backlinks`, `related`, 범주별 `truncated`를 반환한다. 각 목록은 `{id,title,version}`만 최대 20건 반환하며 숨긴 문서 수는 반환하지 않는다. 한 단계 연결만 읽고 전체 그래프를 클라이언트에 보내지 않는다.
- `POST /api/v1/workflows/links/search`: `{query}`(공백 제외 1~200자), 최대 20개 현재 읽기 가능한 제목·ID 일치 후보를 반환한다. 읽기 작업이지만 기존 POST의 인증·CSRF 검사를 유지한다. UI는 250ms 입력 지연 후 후보를 조회하며 수동 검색도 가능하다. 삽입 직전에 다시 검색해 현재 대상과 제목을 확인한다.
- 기존 `GET /workflows/favorites`, `/recent`와 즐겨찾기·구독 버튼을 재사용한다. 새 저장 테이블이나 중복 활동 API는 추가하지 않는다.
- `WorkflowPanel`에 목차, 본문 검색·이전/다음/현재 위치 이동, 개인 목록, 지연 로딩한 주변 문서와 개인 초안 링크 완성을 연결한다. 링크는 기존 `documentHref`를 사용하고 초안 끝에 Markdown으로 삽입한다. 기존 자동 저장·검토 후 발행 경계를 따른다.

## 권한과 관계 의미

`WorkflowService.run`, 현재 membership/인증 재검사, `visiblePageIds`의 원본·계보·상위 문서·휴지통 검사를 재사용한다. 서버는 내부 전체 상태를 현재 ACL로 걸러 목록을 계산하며 결과와 숨긴 제목을 로컬 저장소에 보관하지 않는다. 탐색은 서버의 기존 전체 상태 조회를 사용하므로 큰 공간에서의 조회 비용은 운영 부하 시험이 필요하다.

연결은 기존 `Page.links`와 현재 Markdown의 같은 공간 `/?app=1&space=...&document=...` 링크를 합친다. Markdown 파서의 실제 링크 토큰만 읽어 코드 예시·이미지·다른 공간 링크를 백링크로 계산하지 않는다. 관련 문서는 정확히 같은 태그가 있는 문서다. 의미 유사도나 독립 증거의 관계를 나타내지 않는다.

주변 문서는 펼칠 때 조회하며 닫으면 결과를 비운다. 개인 목록과 열린 주변 문서는 포커스 복귀와 60초마다 현재 권한을 다시 확인하고 요청·오류 때 기존 결과를 비운다. 늦게 도착한 이전 요청은 최신 결과를 덮어쓰지 않는다. 권한 변경의 실시간 푸시 전파는 이 작업에 포함하지 않으며 각 문서 고유 링크를 열 때도 기존 서버 권한 검사를 다시 통과해야 한다. 주변 응답과 표시 본문 버전이 다르면 새로 열도록 안내한다.

## 검증과 한계

자동 테스트는 제목 반복 목차, 코드/표의 리터럴 일치와 위치 이동, 자동완성과 삽입 전 철회, 목록 새로 고침 실패 시 제목 제거, 20건 한도·권한 제외·실제 Markdown 관계를 확인한다. native OIDC UserInfo·세션·CSRF·HTTP·PostgreSQL 경로에서 조회와 원본 권한 철회를 검증한다. 실제 회사 디렉터리나 사내 자료, 성능 및 평가 계약의 대조 실험은 수행하지 않았다. SRH-009의 기존 문서 구독은 유지하며 주제/공간 구독 확대는 별도 로드맵 작업이다.

화면 증거와 환경은 [캡처 기록](../pr-assets/roadmap-navigation/README.md)에 있다. 전체 요구사항의 운영 인수나 완료 상태를 변경하지 않는다.

독립 리뷰 후 링크 삽입은 지연된 권한 응답 시 최신 커밋된 삽입 콜백과 활성 DraftAutosave의 현재 본문을 사용한다. 현재 초안·계정 바인딩을 확인하고, 대기 중 추가 입력을 포함한 동일 값을 화면과 자동 저장으로 전달한다. 실제 WorkflowPanel 입력·지연 응답·포커스 이탈 저장 회귀로 확인했다.

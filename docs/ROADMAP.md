# 제품 로드맵

기존 239개 요구사항을 보존하고 CORE-001~012 핵심 순환 수용 기준을 추가해 총 251개 항목을 추적한다. 단계는 구현 순서이고 운영 범위 축소가 아니다. 모든 항목의 프로덕션 상태는 미검증이다. 로컬 시연은 UI와 도메인 일부가 동작함을 뜻하며 전체 수용 기준 통과가 아니다.

## 다음 구현의 우선순위

1. 기반 권한·자료 등급·사내 UI 계약과 원본 보존 계약을 확정한다.
2. Ingest → Query → Lint의 연속 순환을 실제 사내 모델과 서버 저장소로 구현·평가한다. MCP만 연결하고 지식 누적 엔진을 후순위로 미루지 않는다.
3. 인증된 MCP 도구와 업무 맥락 선택, 실행 결과 환류를 공통 서비스에 연결한다.
4. 지속 작업·무인 일정·삭제와 권한 전파·감사·복구·성능 게이트를 충족한다.

현재 오프라인 편입은 구조 규칙, 질문은 발행본 발췌, Lint는 구조·명시 사실 검사다. 선택적 모델 편입·답변 서버 코드를 제공하며 실제 사내 모델 품질 검증은 남아 있다. 상세 범위는 [핵심 컨셉](LLM_WIKI_CORE.md)과 [에이전트 인터페이스](AGENT_INTERFACE.md)를 따른다.

## 개발 단계

| 단계 | 목적 | 통과 조건 |
| --- | --- | --- |
| P0 기반 계약 | 조직 인증 권한 근거와 UI 계약 | 사내 모듈·IdP·자료 등급 및 API 계약 확정 |
| P1 기능 통합 | 실제 수집 문서 검토 발행 재사용 | 실제 도구와 모델로 통합 및 오류 흐름 검증 |
| P2 운영 준비 | 보안 작업 안정성 관측 복구 | 필수 요구사항 시험 보안 결함 조치 복원 및 인계 완료 |
| P3 조직 확대 | 추가 도구 자료원 공동 편집 규모 | 확대 대상의 권한 부하 및 해당 확장 기능 검증 |

## 현재 데모의 한계

모델을 설정하지 않으면 LLM을 호출하지 않는다. 일정은 자동 실행되지 않는다. 역할·공유·데이터는 브라우저 로컬 시연이다. 의존 문서 집합의 일괄 발행은 현재 단일 로컬 상태 전이이며 다중 탭·다중 사용자와 DB 트랜잭션은 서버에서 구현한다. 수동 편집은 현재 즉시 발행하므로 운영용 초안 흐름으로 교체한다.

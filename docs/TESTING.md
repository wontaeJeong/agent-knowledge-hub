## 브라우저 확인

1. 지식 컴파일에서 기본 원본 등록 후 편입 → 기존 주제 1개와 새 개념 2개 제안
2. 승인과 발행 분리 후 새 페이지·주제 v2 및 연결 확인
3. 발행본 질문과 인용 생성 → 답변 재편입 → 별도 승인·발행
4. 동일 조건 상충 자료 등록·편입·승인·발행 → Weekly에서 실제 상충 값과 원본 두 개 표시
5. 근거 누락·고립·검증일 누락도 실제 데이터에서 표시

모델 중계는 로컬 가짜 OpenAI 호환 서버로 HTTP 계약을 확인했다. 실제 사내 모델에 연결하거나 의미 종합 품질을 측정한 것은 아니다.

## 미검증

실제 사내 모델·SSO·MCP 클라이언트·커넥터·다중 사용자·DB 트랜잭션·무인 일정·부하·침투·복구·Docker·실제 GitHub Actions 실행은 미검증이다. 모바일·스크린리더도 미검증이다. 기존 35개 인수 시나리오는 프로덕션 시험 계획이다. 로컬 테스트 통과를 운영 완료로 승격하지 않는다.

# 검증 기록

검증일 2026년 10월 27일

## 자동 검증

- TypeScript 검사와 Vite 빌드
- Vitest 도메인 불변식 12개
- 원본 239개 요구사항의 ID·수용 기준·로드맵 단계·상태 매핑 검사
- 새 npm ci 설치 후 같은 빌드·검사 통과
- 패키지의 의존성 없는 로컬 실행기로 HTML·브랜드 파일 응답, POST 거부와 없는 파일 404 확인

도메인 시험은 근거를 가진 변경안 생성, 미승인 발행 차단, 동일 자료 중복 편입 방지, 중복 발행 방지, 오래된 기준 버전 차단, 복원 시 현재 범위 유지, 검토자 역할, 독자 쓰기 차단, 제한 자료의 전사 승격 차단, 공유 버전 고정과 만료·철회를 포함한다.

## 브라우저에서 확인한 흐름

합성 데이터와 로컬 저장소로 다음을 실행했다.

1. 홈·문서·수집함·매니저·검토·로드맵 탐색
2. Daily 실행 후 원본 src-python을 가진 변경안 1개 생성
3. 승인과 발행의 분리, 발행 후 문서 v2와 원본 2개 표시
4. 공유 링크 생성·철회 후 접근 불가 표시
5. 새로운 전사 산출물 수동 등록
6. 새로고침 후 등록 자료와 문서 버전 유지
7. v1 복원 후 v3 생성 및 공개 범위 유지
8. 독자 역할의 전사 문서 3개 표시와 등록 버튼 비활성화
9. 로드맵에서 REV-006 검색 및 미구현 상태 확인
10. 라이트·다크 데스크톱 화면의 레이아웃 확인

HTTP 개발 환경에서 crypto.randomUUID가 제공되지 않는 문제를 발견해 getRandomValues 기반 호환 경로로 수정했다. 이 ID는 데모 식별자이며 서버 인증 토큰을 대신하지 않는다.

## 이번에 검증하지 않은 범위

Docker 빌드·실행, 실제 GitHub Actions 실행, 실제 모바일 기기·스크린리더, 다중 브라우저·사용자, 사내 SSO·모델·커넥터, 보안 침투·성능·백업 복원은 미검증이다. 반응형 CSS와 CI·Docker 설정은 제공하지만 실행 사실과 구분한다. 원래 35개 인수 시나리오는 프로덕션 시험 계획이며 이 데모의 통과 보고서가 아니다.

후속 작업에서는 실제 도구 버전의 익명화 fixture, 권한 행렬, 모델 회귀 및 운영 복원 훈련을 추가한다. 시험 결과에는 빌드·모델·프롬프트·정책·데이터 버전을 함께 기록한다.

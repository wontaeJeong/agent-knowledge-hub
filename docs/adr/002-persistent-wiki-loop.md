# ADR 002: 지식 누적 순환을 중심에 둔다

상태: 채택, 2026-10-27.

이전 데모는 문서 관리·검토·승인을 보여주지만 자료 하나를 기존 페이지에 추가하는 데 머물렀다. 카파시의 LLM Wiki 패턴에 맞춰 원본·위키·규칙을 분리하고 Ingest·Query·Lint와 질문 결과의 재편입을 제품의 핵심 경로로 삼는다.

UI의 지식 컴파일 화면은 framework와 독립적인 domain/wiki.ts를 호출한다. 원본 스냅샷, 기존 페이지 기준 버전, 승인한 내용과 의존 변경 집합을 보존한다. 모델 어댑터는 변경안을 만들고 검증과 발행은 별도 상태 전이로 강제한다.

의존성 없는 데모를 위해 명시적 구조를 읽는 오프라인 컴파일러와 발행본 발췌를 제공한다. 선택적 모델 연결은 Node 로컬 중계 경로로 제공하며 실제 의미 종합은 이 모드의 품질 검증 대상이다. 오프라인 규칙 결과를 LLM 호출이나 의미 검증으로 표현하지 않는다.

사내 확장 시 UI는 기존 Gate 프리미티브로 교체하고, 상태 전이·원본·버전·권한을 서버 트랜잭션으로 옮긴다. 현재 로컬 일괄 발행을 다중 사용자 원자성으로 확대 해석하지 않는다. MCP는 공통 지식 서비스의 어댑터로 추가한다. 기존 운영·보안 요구사항을 유지한다.

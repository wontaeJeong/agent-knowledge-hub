# 데모 경계와 제품 연속성

날짜 2026년 10월 27일

현재 목표는 업무 흐름을 실행하며 설명할 수 있는 데모와 사내에서 확장할 소스 레포다. 민감 데이터 없이 반복 시연하기 위해 로컬 저장소와 결정적 매니저를 선택했다. 실제 AI나 서버 권한으로 오인되지 않도록 화면·문서·로드맵에 표시한다.

전체 제품 요구사항은 유지한다. 데모에서 작동하는 부분도 서버·보안·복구 인수 조건이 남아 있으면 미검증 상태로 둔다. UI와 도메인·저장소 경계를 분리해 Gate 컴포넌트 및 사내 백엔드 이식을 가능하게 한다.

실제 다중 사용자와 모델 실행이 필요해지면 브라우저 역할 선택·localStorage·타이머를 프로덕션 구현으로 교체한다. 사용자 동작·문서 ID·근거와 승인 상태의 의미는 보존한다.

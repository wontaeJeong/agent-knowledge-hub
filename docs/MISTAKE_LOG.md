사람이나 에이전트를 탓하기 위한 문서가 아니다. 확인된 사실과 가설·검증 여부를 구분하고, 각 항목을 해결 후에도 지우지 않고 갱신한다. 기록 규칙과 민감 정보 제외 기준은 [PR 운영과 실수 기록](PR_WORKFLOW.md)을 따른다.

### 2026-10-31 — 큰 통합 PR의 충돌과 지연
- 맥락/관련 PR: 운영 기능 체크포인트 [#19](https://github.com/wontaeJeong/agent-knowledge-hub/pull/19)와 병렬 변경 [#18](https://github.com/wontaeJeong/agent-knowledge-hub/pull/18).
- 사실과 영향: 다수 기능을 한 PR에 쌓는 동안 `main`이 바뀌어 재통합과 추가 검증이 필요했다. 두 작업이 같은 마이그레이션 번호를 사용했고, 인증 및 모델 정책 경계도 통합 검토가 필요했다. 작업 완료 보고와 PR 생성이 지연됐다.
- 원인: 독립 가능한 기능 단위의 조기 PR·머지가 부족했고 병렬 변경의 공유 계약을 최종 통합 전 충분히 조정하지 못했다.
- 조치 및 재발 방지: 작은 단위로 PR을 열고 병렬 작업의 마이그레이션 번호·공유 인증/모델 경계를 확인한다. 기존에 배포된 마이그레이션의 내용과 체크섬은 보존한다.
- 검증: #18은 필수 CI 통과 후 머지됨. #19의 최종 통합과 CI는 해당 PR에서 확인한다.
- 상태/후속 작업: #19 검증 진행 중. 이 기록이 향후 충돌을 방지하는 효과는 미확인.

### 2026-10-31 — 테스트에 특정 개발자 컴퓨터 경로 사용
- 맥락/관련 PR: [#19](https://github.com/wontaeJeong/agent-knowledge-hub/pull/19) 감사 저장소 테스트.
- 사실과 영향: 로컬 전용 임시 경로를 테스트에 넣어 Linux GitHub CI에서 디렉터리가 없어 서버 회귀 테스트 2건이 실패했다. 로컬 전체 통과만으로 CI 통과를 보장하지 못했다.
- 원인: 테스트 경로를 운영체제 독립적으로 선택하지 않았다.
- 조치 및 재발 방지: 운영체제의 임시 디렉터리 API를 사용하고 최종 커밋의 Linux CI를 확인한다.
- 검증: 수정 후 로컬 대상 테스트 2건 통과. 최종 GitHub CI는 해당 PR에서 확인한다.
- 상태/후속 작업: 수정됨, 최종 CI 확인 필요.

### 2026-10-31 — 큰 통합 PR의 충돌과 지연
- 맥락/관련 PR: 운영 기능 체크포인트 [#19](https://github.com/wontaeJeong/agent-knowledge-hub/pull/19)와 병렬 변경 [#18](https://github.com/wontaeJeong/agent-knowledge-hub/pull/18).

- 원인: 독립 가능한 기능 단위의 조기 PR·머지가 부족했고 병렬 변경의 공유 계약을 최종 통합 전 충분히 조정하지 못했다.
- 조치 및 재발 방지: 작은 단위로 PR을 열고 병렬 작업의 마이그레이션 번호·공유 인증/모델 경계를 확인한다. 기존에 배포된 마이그레이션의 내용과 체크섬은 보존한다.
- 검증: #18은 필수 CI 통과 후 머지됨. #19의 최종 통합과 CI는 해당 PR에서 확인한다.
- 상태/후속 작업: #19 검증 진행 중. 이 기록이 향후 충돌을 방지하는 효과는 미확인.

- 검증: 이후 실패 원인을 조사하고 집중 테스트를 재실행했다. 최종 통합 검증은 해당 PR에서 확인한다.

### 2026-10-31 — 병렬 기능의 보안·데이터 수명주기 통합 누락
- 맥락/관련 PR: [#18](https://github.com/wontaeJeong/agent-knowledge-hub/pull/18)과 [#19](https://github.com/wontaeJeong/agent-knowledge-hub/pull/19)의 결합.
- 사실과 영향: 동일 접두사의 인증 경로가 기존 경로를 가리고, 신규 인증 기록이 삭제·보존 범위 검사에서 미분류로 차단됐다. 별도 평가 모델은 통합된 원본별 전송 정책을 거치지 않는 경로가 확인됐다. GitHub 서버 회귀가 실패했으며 통합을 검증하기 전에는 머지할 수 없다.
- 원인: 각 PR의 개별 성공만으로 공유 인증 경계·새 저장소·외부 전송의 결합 안전성을 확인할 수 없었다.
- 조치 및 재발 방지: 기존 경로와 새 경로를 구분하고, 새 저장소의 공간 경계·삭제·보존·복원 영향을 검사한다. 평가 모델은 별도 목적지 및 원본 승인을 요구한다. 보안 검사를 완화하거나 테스트 실패를 숨기지 않는다.
- 검증: 관련 대상 테스트를 실행 중이며 최종 결과와 남은 한계는 #19를 따른다.
- 상태/후속 작업: 통합 검증 및 독립 안전 검토 중.
